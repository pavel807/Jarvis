# Jarvis — голосовой ассистент на Rust

Локальный голосовой ассистент для macOS: wake word → команды → ответы локальной LLM.
Работает полностью офлайн (кроме первого скачивания моделей).

## Архитектура

```
Cargo workspace
├── crates/jarvis-tts    — production-движок TTS: Qwen3-TTS 0.6B CustomVoice,
│                          вендорено из TrevorS/qwen3-tts-rs (MIT) и сокращено
│                          до 0.6B; candle 0.11 + Metal, mmap-загрузка весов
├── crates/jarvis-core   — движок: wake word, STT, TTS, LLM, команды, события
├── crates/jarvis-cli    — headless-запуск из терминала
└── app/                 — GUI (Tauri 2 + Vue 3)
    ├── src/             — страницы интерфейса
    └── src-tauri/       — бэкенд приложения (трей, IPC, обучение wake word)
```

Подсистемы:
- **Wake word** — RustPotter (NN-модель `.rpw`), обучение прямо из интерфейса.
- **STT** — GigaAM v3 (ONNX int8, русский).
- **TTS** — Qwen3-TTS 0.6B CustomVoice (candle + Metal, чистый Rust без Python/C++):
  нейросинтез с естественной русской интонацией (русский — один из 10 официальных
  языков), 9 preset-голосов, RTF ~0.7 на Metal, mmap-загрузка весов без F32-копий,
  retry при разовых отказах Metal-аллокации, автозагрузка модели при отсутствии,
  кэш синтеза с LRU-очисткой.
- **LLM** — Qwen3-1.7B на candle + Metal, собственная реализация инференса
  (GQA, QK-norm, явный head_dim, KV-кэш), стриминг ответа в TTS по предложениям.
- **Команды** — `commands.toml` с hot-reload, fuzzy-матчинг (Левенштейн).

## Требования

- macOS (Apple Silicon — Metal обязателен для LLM/TTS), Xcode с компонентом **Metal Toolchain**
  (`xcodebuild -downloadComponent MetalToolchain`)
- Rust (stable, edition 2024), [bun](https://bun.sh)
- ~8 ГБ RAM под модели (STT + TTS + LLM одновременно)
- Доступ в интернет при первом запуске: скачиваются GigaAM (~250 МБ),
  Qwen3-1.7B (~3.4 ГБ) и Qwen3-TTS (~2.5 ГБ) в `models/`

## Запуск CLI (headless)

```bash
cargo run --release -p jarvis-cli
```

Скажите «Джарвис» — прозвучит сигнал, дальше говорите команду или вопрос.

## Запуск GUI

```bash
cd app
bun install
bun tauri dev
```

Приложение живёт в трее (менюбаре): клик — открыть окно, закрытие окна сворачивает
в трей, «Выход» в меню трея завершает. Автозапуск при входе в систему — плагин
autostart (управляется из кода/настроек).

## Интерфейс

- **Дашборд** — статус подсистем, пауза прослушивания, журнал событий.
- **Wake Word** — запись сэмплов («Джарвис» + фоновый шум), обучение NN-модели
  (tiny/small/medium) с прогрессом, тест score, подмена модели на лету.
- **Команды** — редактор `commands.toml`: триггеры, типы (`url`, `search`, `app`,
  `stop`, `exit`, `command`), приоритет = порядок.
- **Голос** — список голосов модели, проверка озвучки.
- **Чат с ИИ** — проверка локальной LLM со стримингом.
- **Настройки** — пороги VAD/wake word, окно follow-up, параметры LLM и голоса
  (всё это лежит в `settings.toml` и подхватывается на лету).

## Конфиги и данные

| Путь                  | Назначение                                   |
| --------------------- | -------------------------------------------- |
| `commands.toml`       | голосовые команды                            |
| `settings.toml`       | пороги, LLM, голос (создаётся при сохранении)|
| `models/`             | модели (кэш, не коммитится)                  |
| `train/jarvis*/`      | сэмплы wake word                             |
| `resources/audio/`    | звуки-ответы (ok1-4, reply1)                 |
| `resources/tts_cache/`| кэш синтеза (до 300 МБ, LRU)                 |

Корень данных переопределяется переменной `JARVIS_HOME`.

## Тесты

```bash
cargo test -p jarvis-core
```

Покрыты: нормализация текста, Левенштейн/матчинг команд, шаблон ChatML,
сэмплинг (repeat penalty / top-p), фильтр `<think>`, ресемплинг/даунмикс.

## Спайк LLM

```bash
cargo run --release --example llm_spike -p jarvis-core
```

Загружает модель на Metal и задаёт контрольные вопросы (EN/ZH/RU).

## Известные ограничения

- LLM-загрузка при старте занимает память заранее; на 8 ГБ машинах возможны
  свопы — снижайте до Qwen3-0.6B.
- Ответы LLM озвучиваются по предложениям; отмена («замолчи») срабатывает
  между токенами.
- Для сборки `.app` нужны иконки всех размеров: `cd app && bun tauri icon icons/icon.png`.

# Джарвис — голосовой ассистент для компьютера

Имя по умолчанию — Джарвис, но ассистента можно назвать как угодно
(Настройки → Общие → «Имя ассистента»), и фразу-активацию тоже можно
поменять на любую.

Джарвис слушает активационную фразу, выполняет команды и отвечает
на вопросы голосом. Всё работает на твоём компьютере:
речь распознаётся локально, голос синтезируется локально, ответы готовит
модель — локальная или облачная, на твой выбор.

Для macOS, Linux и Windows.

## Что Джарвис умеет

**Голос и общение**
- Слушает фразу-активацию от любого человека (фразу можно поменять в настройках)
- Отвечает голосом, читает по-русски правильно: числа, даты, «запуск» vs «замок»
- Понимает, когда перебивают: скажи «замолчи» — остановится сразу
- Можно писать текстом — окно ввода на главной (микрофон прямо в нём)
- Помнит разговор: «мы это забыли» — вернётся к теме, о которой забыли
- Запоминает, что ты рассказал о себе («запомни, что я вегетарианец»)

**Команды и действия**
- Открывает сайты, программы и файлы: «открой ютуб», «запусти монтажку»
- Управляет окнами: «сверни хром», «во весь экран»
- Таймеры и будильники: «таймер на 5 минут», «разбуди в 7 утра»
- Музыка: «поставь на паузу», «следующий трек», «включи что-нибудь бодрое»
- Громкость, яркость, скриншот, блокировка, буфер обмена
- Ищет в интернете: «какая погода», «что нового по релизу» — и отвечает сводкой
- Глубокое исследование: «исследуй рынок электрокаров» — сам ищет в нескольких
  местах и собирает ответ с источниками
- Работает с файлами: «зайди в проект, найди функцию X, поправь её»
- Твой список команд: добавь свои слова-триггеры и действия в разделе «Команды»
- Задачи по расписанию: «каждое утро в 8 собери новости» — сделает само

**Telegram**
- Впитай токен бота — и Джарвис отвечает тебе в Telegram тем же мозгом
- Из Telegram он может исполнять те же команды: «открой ютуб», таймеры и т.д.
  (выключается переключателем в настройках)
- Чужие чаты бот игнорирует — отвечает только в разрешённых

**Безопасность**
- Каждый шаг подтверждается по факту: файл перечитан, музыка реально играет —
  «сделано» звучит только когда это правда
- Непонятные и недоступные действия — честный отказ с причиной

## Установка

Нужны два инструмента:
1. [Rust](https://rustup.rs) — язык сборки
2. [bun](https://bun.sh) — сборка интерфейса

Дальше три команды:

```bash
git clone https://github.com/pavel807/Jarvis
cd Jarvis/app
bun install && bun tauri dev
```

Первый запуск скачает модели автоматически (~4 ГБ, один раз):
распознавание речи, синтез голоса и модель ответов. Дальше Джарвис
стартует за несколько секунд и работает офлайн.

Приложение живёт в трее: закрытие окна сворачивает его в трей,
клик по значку — открыть.

## Первый запуск

Приложение проведёт по трём шагам:
1. Загрузит модели (прогресс показывается)
2. Предложит выбрать «мозг»: Яндекс GPT (облако), своя модель через API
   или Qwen 3.5 локально
3. Предложит выбрать голос — их 29, от строгих до мягких

## Как пользоваться

1. Скажи «Джарвис» — прозвучит сигнал, Джарвис слушает
2. Скажи команду или вопрос: «какая погода», «открой ютуб», «таймер на 10 минут»
3. «замолчи» — остановить ответ; «мы это забыли» — вернуться к прошлой теме

Хочешь другую фразу-активацию («Компьютер», «Робот» и т.д.) — Настройки →
Wake word и голос — дополнительно. Фраза проверяется автоматически: ты
увидишь, сколько вариантов произнесения Джарвис понимает.

История диалога — раздел «Память», там же список задач.

## Настройки (по-человечески)

- **Модель** — три варианта: Яндекс GPT (нужен ключ), своя модель через API,
  Qwen 3.5 локально (качается кнопкой «Скачать»)
- **Голос и скорость** — 29 голосов, прослушивание перед выбором
- **Общие** — имя ассистента, звук перед ответом, автозапуск при входе
- **Микрофон** — доступ и «только мой голос» (скоро)
- **Telegram** — токен бота, чаты, выполнение команд

Всё остальное (пороги тишины, длина окна) Джарвис подбирает сам —
в интерфейсе этого нет, чтобы не путать.

## Типовые проблемы

- **Не реагирует на «Джарвис»** — проверь доступ к микрофону (Настройки →
  Микрофон). Название фазы проверь: фраза должна совпадать
- **Первый запуск долгий** — качаются модели, один раз
- **Не слышно голоса** — голос подгружается в первую минуту после старта
- **Не понимает фразу** — добавь свои слова-триггеры в разделе «Команды»

## Для разработчиков

Структура:

```
crates/jarvis-core  — движок: распознавание, синтез, модель, команды
crates/jarvis-cli   — запуск без интерфейса (cargo run -p jarvis-cli)
app                 — интерфейс (Tauri 2 + Svelte 5)
```

Тесты движка:

```bash
cargo test -p jarvis-core
```

Проверка интерфейса без движка (мок IPC, горячая правка вёрстки):

```bash
cd app && bun run dev   # http://localhost:1420/dev/preview.html
```

Тонкие параметры — в `settings.toml` в папке данных (`~/.jarvis` на Linux,
`~/Library/Application Support/Jarvis` на macOS): пороги тишины, длина
окна детектора, температура модели. Файл перечитывается на лету.

## Модели и лицензии

- Распознавание речи: FastConformer-Hybrid Large RU (NVIDIA, CC-BY-4.0),
  собственная реализация, работает на процессоре
- Голос: Silero v5 (AGPL-3.0 / CC-BY-NC — для личного помощника), 29 голосов
- Ударения и омографы: модели ruaccent
- Модель ответов: Qwen 3.5 (Apache-2.0) локально или любая облачная через API

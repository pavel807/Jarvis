# Плагины-автоматизации (Spark)

Каждый `.sk`-файл в этом каталоге (и в `~/.local/share/Jarvis/plugins`) —
автоматизация на языке [Spark](https://github.com/pavel807/Spark). При запуске
ассистент компилирует плагин в нативный бинарник (кэш по хэшу исходника в
`~/.local/share/Jarvis/plugins_cache`) и даёт модели инструмент `plugin_<имя>`.

## Шапка плагина (в комментариях `#`)

```
# плагин: уведомление
# описание: показывает системное уведомление с заданным текстом
# аргументы: текст
```

- `плагин:` — имя (инструмент станет `plugin_уведомление`); без него — имя файла
- `описание:` — что делает; это видит модель
- `аргументы:` — подсказка по аргументам (`нет`, если аргументов не нужно)

## Built-ins

| Spark | Что делает |
|---|---|
| `arg(1)` | аргумент командной строки №1 |
| `env("HOME")` | переменная окружения |
| `run("uptime -p")` | shell-команда, stdout |
| `read_file("путь")` / `write_file("путь", "текст")` | файлы |
| `notify("заголовок", "текст")` | системное уведомление |
| `say("фраза")` | фраза, которую Джарвис озвучит голосом |
| `str(x)` / `int(x)` | приведение типов |

## Автоматизация ОС (v0.3) — как AutoHotkey, но кроссплатформенно

| Spark | Русский синоним | Что делает |
|---|---|---|
| `send_hotkey("CTRL+SHIFT+T")` | `сочетание("…")` | нажать сочетание клавиш в активное окно |
| `type_text("текст")` | `напечатать("…")` | напечатать текст (на Wayland юникод нативно) |
| `mouse_click(x, y)` / `mouse_right_click(x, y)` | `клик(x, y)` | клик по координатам (нужен ydotool) |
| `mouse_move(x, y)` / `mouse_scroll("down", 3)` | `движение_мыши` / `прокрутка` | курсор и прокрутка |
| `window_list()` | `окна()` | список открытых окон «класс — заголовок» |
| `window_focus("firefox")` | `фокус("…")` | фокус на окно по классу или заголовку |
| `window_close("firefox")` | `закрыть_окно("…")` | закрыть окно |
| `window_minimize("zed")` / `window_maximize("zed")` | `свернуть_окно` / `развернуть_окно` | размер окна |
| `window_move_desktop("zed", 3)` | `перенести_окно("…", 3)` | перенести окно на стол |
| `desktop_switch(3)` / `desktop_next()` / `desktop_prev()` | `стол(3)` / `следующий_стол()` / `предыдущий_стол()` | рабочие столы |
| `volume_set(50)` / `volume_get()` / `volume_mute()` | `громкость` / `без_звука` | звук |
| `brightness_set(70)` | `яркость(70)` | яркость экрана |
| `screenshot("/tmp/shot.png")` | `скриншот("…")` | снимок экрана в файл |
| `clip_set("текст")` / `clip_get()` | `в_буфер("…")` / `буфер()` | буфер обмена |
| `http_get("https://…")` | `запрос("…")` | HTTP GET, тело ответа |
| `app_open("firefox")` / `app_quit("firefox")` | `открыть_приложение` / `закрыть_приложение` | запуск и закрытие приложений |
| `battery()` | `батарея()` | заряд в процентах |
| `screen_size()` | `экран_размер()` | «1920x1080» |
| `sleep_ms(500)` | `пауза(500)` | паува в миллисекундах |

Окна и столы — через Hyprland (Wayland); на macOS/Windows эти функции честно
отвечают «поддержано пока на Linux», остальное (клавиатура, звук, буфер,
скриншот, приложения) работает на всех трёх системах.

## Строковые методы (питоновские)

`s.upper()` / `s.lower()` / `s.trim()` / `s.replace("a", "b")` /
`s.contains("x")` / `s.startswith("x")` / `s.endswith("x")` / `s.len()` /
`s.split(",")` (даёт список) / `",".join(список)` / `s.find("x")` |

Строки склеивайте через `"литерал" + переменная`, циклы — `for x in ["а","б"]`.
Функции (`def`) возвращают строки; русский текст в именах разрешён.

## Исполнение и контракт

- таймаут 30 с, зависший плагин останавливается;
- ненулевой код выхода — честная неудача, stderr попадает в detail;
- строка `SAY: …` на stdout — то, что ассистент произнесёт.
